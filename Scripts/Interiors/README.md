# 3D Models — 0.1.19

Original furniture, appliances, props and selected exterior models for Viewpoint.
The pack declares 1,128 models for 2,057 sprites. Native Aim is separate and optional.

All custom window models, glass, facade/aperture changes and roof/gutter/trim/HVAC
corrections have been removed. Native windows and world geometry remain with the
game and Viewpoint. The retained client helpers cover model-specific support heights,
sink/counter placement, rugs, exterior-object visibility and the optional Potato setting.
No native Surface property mutation remains.

Requires PZ42.21, Viewpoint and base ZombieBuddy2.3.4 or newer. ZombieBuddy Extensions
is optional. See [release notes](../../Docs/PATCH-0.1.19.md) and
[build instructions](../../Docs/DEVELOPMENT.md). Sources are in `source/local/vpinteriors`;
the model manifest is `mod/42/media/modelpacks/furniturefix/pack.properties`.

Offline loading, geometry, hook, support and native fallback checks passed.
Live multiplayer and FPS measurements remain pending. Many textures are unfinished
and some models still have visual bugs. The focus is model/material quality.
